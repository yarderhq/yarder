⍰ FAQ

Frequently Asked Questions

If you have a question that is not answered here, please email us.

What is yarder?

yarder is a developer tool for solo Node developers who want to self-host without becoming a DevOps engineer. You describe processes in a yarder.yaml. yarder dev runs them as native processes on your laptop with a GUI. yarder deploy ships that same stack to a VPS you own.

Do I need Docker to use yarder?

No. App services are start commands and directories. Postgres and Redis are managed capabilities you ask for — you do not author a Compose file. Docker is not the product surface.

Is yarder a Coolify alternative?

Same job — self-host on a server you own — different model. Coolify is Docker and Compose shaped. yarder is application shaped: processes, directories, and a yaml that is not Compose. Railway and Render still win if you want zero servers.

Can I deploy to production with yarder today?

Yes. yarder remote add points at a VPS you already have. yarder deploy syncs the same yarder.yaml, starts processes with PM2, writes nginx, and issues TLS when DNS is ready.

Is yarder free?

Yes. yarder is open source under the GNU Affero General Public License v3.0. Apps you run or deploy with yarder stay yours — using the CLI does not place your application under the AGPL. You still pay your VPS provider if you self-host.

Is yarder open source?

Yes. Source is AGPL-3.0-only . Pull requests are welcome; see CONTRIBUTING.md. Contributions require signing a CLA.
